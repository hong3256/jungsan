# 🏓 진홍이가 만든 참석앱

C-PICK 피클볼 동호회용 **참석 투표 + 1/N 정산** 웹 앱(PWA)입니다.
모임은 두 가지 — **🏓 번개게임**(매일 하는 정기 게임)과 **🍻 번개회식**(가끔 하는 회식) — 이고, 둘 다 총 사용료를 넣으면 **10원 미만 절사 1/N 정산**이 됩니다.
카톡 인앱 브라우저에서 한 손으로 쓰도록 만들었고, 홈 화면에 추가하면 **`진홍이가 만든 참석앱`** 이름으로 앱처럼 열립니다.

- 주소: https://hong3256.github.io/jungsan/
- 구글 시트: 진홍님 드라이브의 **비공개** 시트 `C-PICK 참석·번개 관리` (모임목록 / 참석기록 / 설정)
- 이 저장소에는 **회원 개인정보(전화번호·생년월일·주소)가 한 글자도 없습니다.** 이름만 다룹니다.

## 1. 무엇을 하나요

| 기능 | 설명 |
| --- | --- |
| 🏓 번개게임 / 🍻 번개회식 / 📋 전체 | 탭으로 나눠 보고, 오늘 · 예정 · 지난 모임 순서로 보여 줍니다 |
| ✅ 참석 / ❓ 미정 / ❌ 불참 | 내 이름을 한 번 넣으면 기기에 기억되고, 버튼 한 번으로 바로 반영(4초마다 자동 새로고침) |
| 💰 1/N 정산 (두 모임 모두) | 카드의 `총 사용료` 칸에 금액을 넣고 `저장`하면 **`1인당 = 내림(총액 ÷ 참석인원 ÷ 10) × 10`** 로 자동 계산 |
| 🕗 나중에 금액 입력 | 모임은 **0원으로 먼저 만들고**, 끝난 뒤 카드에서 금액만 넣고 `저장`해도 됩니다 |
| 💡 자투리 표시 | `1인당 × 인원`과 총액의 차이(10원 미만 절사분)를 작게 보여 줌 |
| 🔗 제목 옆 복사 | 모임 카드 **제목 옆 `🔗 복사`** 를 누르면 `🏓 [번개게임] 화요일 번개게임` · `📅 11/24(화) 19:00 · 송암 에어돔 1번코트` · `👇 눌러서 참석 투표하기` · **이 모임만 여는 주소(`…?ev=모임ID`)** 를 한 번에 복사합니다. 카톡방에 붙이면 제목·일시·링크가 그대로 들어가고, **링크를 누르면 그 모임 탭이 열리고 카드로 이동**(2~3초 강조)합니다 |
| 👤 주최자 | 모임 만들기·수정 창의 **`제목 / 메모` 바로 아래 `주최자`** 칸에 이름을 넣으면, 카드 제목 아래 **`👤 주최: 이름`**, `🔗 복사`·`📋 카톡 정산 복사` 문구에도 `👤 주최: 이름` 한 줄이 들어갑니다. 새 모임을 만들 때는 **내 이름이 미리 채워지고**(지우면 표시 안 함), 수정할 때는 저장된 주최자가 그대로 나옵니다 |
| 📋 카톡 정산 복사 | 모임명·날짜·참석자·총 사용료·1인당 금액을 카톡방에 바로 붙여넣을 문구로 복사 |
| 🏦 송금 안내 선택 | 정산 문구를 열면 **`🏦 계좌번호 입력`**(계좌·예금주를 넣으면 문구에 자동으로 들어감) 또는 **`💬 카톡으로 보내주세요`** 중 하나를 고를 수 있고, 고른 방식이 문구 맨 아래에 붙습니다. 계좌·예금주는 **이 기기에만** 저장되어 다음 정산에 자동으로 채워집니다 |
| 🔒 관리자(PIN) | 모임 마감/재개, 수정, 삭제, 지난 모임 정리, **모두 지우기** |

### 계산 예시
| 총 사용료 | 참석 | 1인당 | 실제 걷는 돈 | 자투리 |
| --- | --- | --- | --- | --- |
| 50,000원 | 7명 | **7,140원** | 49,980원 | 20원 |
| 30,000원 | 7명 | **4,280원** | 29,960원 | 40원 |
| 30,000원 | 8명 | **3,750원** | 30,000원 | 0원 |
| 30,000원 | 0명 | — | — | (참석자가 없으면 나누지 않음) |

> 화면에는 `번개게임`·`번개회식`으로 보이지만, 구글 시트 `모임목록`의 `구분` 열에는 예전 값인 `정기`·`번개`가 그대로 저장됩니다.
> (이미 배포된 Apps Script 를 다시 배포하지 않아도 되도록 서버와 주고받는 값은 그대로 두었습니다. `정기` = 번개게임, `번개` = 번개회식)

> 주최자도 같은 이유로 **시트에는 `제목/메모` 칸에 `[주최:이름] 제목`** 형태로 저장됩니다(예: `[주최:이진홍] 화요일 번개게임`).
> 앱 화면·카톡 문구에서는 태그를 떼고 제목과 `👤 주최: 이름` 을 따로 보여 주므로, **Apps Script 재배포 없이** 바로 동작합니다.

## 2. 처음 한 번만 — 구글 시트와 연결

앱은 구글 시트에 붙인 **Apps Script 웹 앱**과 이야기합니다. (시트와 스크립트는 진홍님 계정 안에만 있습니다)

1. 구글 시트 `C-PICK 참석·번개 관리`를 엽니다.
   - 탭 3개: `모임목록`, `참석기록`, `설정`(A1 `관리자PIN` = `0629`, A2 `절사단위` = `10`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 열고, 받은 파일
   `cpick-attendance-apps-script.txt` 내용을 전부 붙여넣고 저장합니다.
3. **배포 → 새 배포**
   - 유형: **웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - → 배포 후 나오는 주소(`https://script.google.com/macros/s/.../exec`)를 복사
4. 앱(https://hong3256.github.io/jungsan/)을 열고 오른쪽 위 **🔗** → 주소를 붙여넣고 **연결**.
   - 한 번 넣으면 그 기기에 저장되어 다음부터 자동 연결됩니다.
   - 코드 안 `DEFAULT_SYNC_URL` 에 미리 넣어 두면 모든 기기에서 바로 연결됩니다.
5. 동호회원에게는 **앱 주소만** 알려 주세요. (같은 주소를 쓰면 같은 시트를 함께 봅니다)

> 🔗 를 누르지 않고 그냥 쓰면 **이 기기에만 저장**되는 연습 모드로 동작합니다(다른 사람과 공유되지 않음).

## 3. 쓰는 법

1. 위쪽 **내 이름**에 이름을 넣습니다(한 번만; 기기에 저장).
   - 이미 투표한 사람이 있으면 **👥** 를 눌러 목록에서 고를 수도 있습니다.
2. **＋ 새 모임** → 구분(**🏓 번개게임 / 🍻 번개회식**) · 날짜(기본 오늘) · 시간 · 장소 · 제목 · **주최자**(제목 바로 아래, 내 이름이 미리 채워짐 · 지워도 됨) · **총 사용료**.
   - 총 사용료는 두 모임 모두에서 입력할 수 있고, **모르면 0원으로 두고 나중에** 넣어도 됩니다(2만~5만원 빠른 버튼 있음).
3. 카드에서 **✅ 참석** 만 누르면 끝. 잘못 눌렀으면 다른 버튼을 다시 누르면 바뀝니다.
4. 모임이 끝나면 카드의 **총 사용료**에 금액을 넣고 **저장** → 1인당 금액·자투리가 바로 다시 계산됩니다.
5. **📋 카톡 정산 복사** → 카톡방에 붙여넣기. (문구 머리: `🏓 C-PICK 번개게임 정산` / `🍻 C-PICK 번개회식 정산`)
   - 열린 창 위쪽 **송금 안내**에서 방식을 고릅니다.
     - **🏦 계좌번호 입력**: `은행 / 계좌번호` + `예금주(계좌명)` 를 넣으면 문구 맨 아래에 `🏦 입금 계좌: 국민은행 123-45-6789012 이진홍` 처럼 들어갑니다. 한 번 넣으면 기기에 저장되어 다음부터 자동으로 채워지고, `지우기`로 지울 수 있습니다.
     - **💬 카톡으로 보내주세요**: 문구 맨 아래에 `💬 카톡으로 보내주세요` 가 들어가고 계좌 칸은 숨겨집니다.
   - 방식을 바꾸거나 계좌를 고치면 문구가 그 자리에서 바로 바뀝니다. 문구는 직접 고쳐도 되고, **📋 문구 복사** 로 다시 복사할 수 있습니다.
6. 새 모임을 카톡방에 알릴 때는 카드 **제목 옆 `🔗 복사`** → 카톡방에 붙여넣기.
   - `🏓 [번개게임] 화요일 번개게임` / (`👤 주최: 이진홍` — 주최자를 넣었을 때만) / `📅 오늘 11/24(화) 19:00 · 송암 에어돔 1번코트` / `👇 눌러서 참석 투표하기` / `https://hong3256.github.io/jungsan/?ev=…` 가 한 번에 들어가고, 받은 사람이 **링크를 누르면 그 모임 탭이 열리며 카드로 이동**합니다(2~3초 노란 테두리로 표시).
   - 카톡 인앱처럼 자동 복사가 막히는 곳에서는 글자가 선택된 채 창이 열리니, 길게 눌러 `복사` 하면 됩니다.

### 관리자 모드
- 오른쪽 위 **🔒** → PIN `0629` (시트 `설정` 탭 A1 값을 바꾸면 PIN도 바뀝니다)
- 카드마다 **🔒 마감 / 🔓 재개**, **✏️ 수정**, **🗑 삭제** 가 나타납니다.
- 목록 위 **🧹 지난 모임 N개 정리** 로 지난 날짜 모임을 한 번에 지웁니다.
- 목록 위 **🗑️ 모두 지우기** 로 **등록된 모든 모임과 참석 기록**을 지웁니다(확인창 한 번).
  - 관리자 모드에서만 보이고, 서버에는 `deleteEvent`(모임ID + PIN)를 하나씩 호출해 지웁니다 — Apps Script 재배포 불필요.
- 마감된 모임은 참석 버튼이 잠깁니다(정산이 끝난 모임 보호).

### 검증 결과 (2026-11-24, v8)
- 주최자 검증 **52/52 통과** — 새 모임 창에서 `제목/메모` 바로 아래 `주최자` 칸(라벨·placeholder `예) 이진홍`·20자), 내 이름 자동 채움, 생성 후 카드 제목 아래 `👤 주최: 이름`(제목·장소 사이) 표시, 시트 `제목/메모` 칸에 `[주최:이름] 제목` 저장, `✏️ 수정` 창에서 제목/주최자 분리 로드·수정 반영, `🔗 복사`·`📋 카톡 정산 복사`에 `👤 주최:` 줄 포함(태그 미노출), 주최자를 비우면(수정에서 지운 경우 포함) 카드·시트·문구가 기존과 100% 동일, 제목 없이 주최자만 있어도 구분명 표시, 다른 화면(같은 시트)에서도 표시, 콘솔 오류 0건.
- 모임 링크 복사·딥링크 검증 **30/30 통과** — 390px에서 제목·`🔗 복사`가 한 줄에 넘침 없이 배치, 복사 문구 4줄(`🏓 [번개게임] 제목` / `📅 날짜 시간 · 장소` / `👇 눌러서 참석 투표하기` / `앱주소?ev=모임ID`), 장소 없을 때 `·` 생략, 제목이 없으면 구분만, 복사 성공 토스트, 자동 복사가 막히면 직접 복사 창(문구 그대로), `?ev=`로 열면 해당 탭 자동 선택·카드로 스크롤·2~3초 강조 후 해제, 목록에 10개만 보이는 오래된 모임도 딥링크로 표시, 없는 `?ev=NOPE`는 `찾으려는 모임이 없어요` 안내, 콘솔 오류 0건.
