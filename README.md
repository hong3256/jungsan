# 🏓 C-PICK 참석·정산

C-PICK 피클볼 동호회용 **매일 참석 투표 + 번개 모임 1/N 정산** 웹 앱(PWA)입니다.
카톡 인앱 브라우저에서 한 손으로 쓰도록 만들었고, 홈 화면에 추가하면 앱처럼 열립니다.

- 주소: https://hong3256.github.io/cpick-attendance/
- 구글 시트: 진홍님 드라이브의 **비공개** 시트 `C-PICK 참석·번개 관리` (모임목록 / 참석기록 / 설정)
- 이 저장소에는 **회원 개인정보(전화번호·생년월일·주소)가 한 글자도 없습니다.** 이름만 다룹니다.

## 1. 무엇을 하나요

| 기능 | 설명 |
| --- | --- |
| 📅 매일 정기 / ⚡ 번개 모임 / 📋 전체 | 탭으로 나눠 보고, 오늘 · 예정 · 지난 모임 순서로 보여 줍니다 |
| ✅ 참석 / ❓ 미정 / ❌ 불참 | 내 이름을 한 번 넣으면 기기에 기억되고, 버튼 한 번으로 바로 반영(4초마다 자동 새로고침) |
| 💰 번개 1/N 정산 | 총 사용료를 넣으면 **`1인당 = 내림(총액 ÷ 참석인원 ÷ 10) × 10`** 로 자동 계산 |
| 💡 자투리 표시 | `1인당 × 인원`과 총액의 차이(10원 미만 절사분)를 작게 보여 줌 |
| 📋 카톡 정산 복사 | 모임명·날짜·참석자·총 사용료·1인당 금액을 카톡방에 바로 붙여넣을 문구로 복사 |
| 🔒 관리자(PIN) | 모임 마감/재개, 수정, 삭제, 지난 모임 정리 |

### 계산 예시
| 총 사용료 | 참석 | 1인당 | 실제 걷는 돈 | 자투리 |
| --- | --- | --- | --- | --- |
| 50,000원 | 7명 | **7,140원** | 49,980원 | 20원 |
| 30,000원 | 7명 | **4,280원** | 29,960원 | 40원 |
| 30,000원 | 8명 | **3,750원** | 30,000원 | 0원 |
| 30,000원 | 0명 | — | — | (참석자가 없으면 나누지 않음) |

## 2. 처음 한 번만 — 구글 시트와 연결

앱은 구글 시트에 붙인 **Apps Script 웹 앱**과 이야기합니다. (시트와 스크립트는 진홍님 계정 안에만 있습니다)

1. 구글 시트 `C-PICK 참석·번개 관리`를 엽니다.
   - 탭 3개: `모임목록`, `참석기록`, `설정`(A1 `관리자PIN` = `0629`, A2 `절사단위` = `10`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 열고, 받은 파일
   `cpick-attendance-apps-script.txt` 내용을 전부 붙여넣고 저장합니다.
3. **배포 → 새 배포**
   - 유형: **웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - → 배포 후 나오는 주소(`https://script.google.com/macros/s/.../exec`)를 복사
4. 앱(https://hong3256.github.io/cpick-attendance/)을 열고 오른쪽 위 **🔗** → 주소를 붙여넣고 **연결**.
   - 한 번 넣으면 그 기기에 저장되어 다음부터 자동 연결됩니다.
   - 코드 안 `DEFAULT_SYNC_URL` 에 미리 넣어 두면 모든 기기에서 바로 연결됩니다.
5. 동호회원에게는 **앱 주소만** 알려 주세요. (같은 주소를 쓰면 같은 시트를 함께 봅니다)

> 🔗 를 누르지 않고 그냥 쓰면 **이 기기에만 저장**되는 연습 모드로 동작합니다(다른 사람과 공유되지 않음).

## 3. 쓰는 법

1. 위쪽 **내 이름**에 이름을 넣습니다(한 번만; 기기에 저장).
   - 이미 투표한 사람이 있으면 **👥** 를 눌러 목록에서 고를 수도 있습니다.
2. **＋ 새 모임** → 구분(정기/번개) · 날짜(기본 오늘) · 시간 · 장소 · 제목.
   번개는 **총 사용료**까지 넣습니다(2만~5만원 빠른 버튼 있음).
3. 카드에서 **✅ 참석** 만 누르면 끝. 잘못 눌렀으면 다른 버튼을 다시 누르면 바뀝니다.
4. 번개 모임은 총 사용료를 고친 뒤 **저장** → 1인당 금액이 바로 다시 계산됩니다.
5. **📋 카톡 정산 복사** → 카톡방에 붙여넣기.

### 관리자 모드
- 오른쪽 위 **🔒** → PIN `0629` (시트 `설정` 탭 A1 값을 바꾸면 PIN도 바뀝니다)
- 카드마다 **🔒 마감 / 🔓 재개**, **✏️ 수정**, **🗑 삭제** 가 나타납니다.
- 목록 위 **🧹 지난 모임 N개 정리** 로 지난 날짜 모임을 한 번에 지웁니다.
- 마감된 모임은 참석 버튼이 잠깁니다(정산이 끝난 모임 보호).

## 4. 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 전체(화면·계산·투표·정산·관리자). 외부 라이브러리 없음 |
| `manifest.json` | 홈 화면 추가(PWA) 설정 |
| `sw.js` | 오프라인에서도 화면이 열리도록 캐시 (화면 고칠 때 `VERSION` 올리기) |
| `icon-192.png` `icon-512.png` `icon-maskable-512.png` `apple-touch-icon.png` `favicon.ico` `icon-1024.png` | 아이콘 |
| `tools/make_icons.py` | 아이콘 다시 만들기 |
| `tools/test_apps_script.py` | Apps Script(doGet/doPost) 전 동작 단위 검증 — 시트 목(mock) 사용 |
| `tools/e2e_test.py` | 모바일 390px·데스크톱 화면에서 앱 전체 동작 검증(Playwright) |

### 검증 결과 (2026-11-24)
- Apps Script 단위 검증 **52/52 통과** — 생성·투표(중복 갱신)·사용료·PIN·마감·수정·삭제·지난 모임 정리·잘못된 입력·시트 날짜/시간 셀 방어·잠금.
- 화면 검증 **52/52 통과** — 정기/번개 만들기, 7명 투표, 5만원→7,140원, 3만원→4,280원(자투리 40원), 참석 0명, 카톡 문구·클립보드 복사, 다른 사람 투표가 4초 안에 반영, PIN 마감·재개·수정·삭제·지난 모임 정리, 연결 끊김 표시, 로컬 모드, 콘솔 오류 0건.

테스트 실행:
```bash
python3 tools/test_apps_script.py ../downloads/cpick-attendance-apps-script.txt
python3 tools/e2e_test.py ../downloads/cpick-attendance-apps-script.txt
```

## 5. 개인정보

- 앱과 시트에는 **이름**만 저장합니다. 전화번호·생년월일·주소는 받지도 저장하지도 않습니다.
- 구글 시트는 진홍님 계정 소유의 비공개 문서이고, 이 저장소(공개)에는 시트 주소나 회원 정보가 들어 있지 않습니다.
- 웹 앱 주소를 아는 사람은 누구나 참석 투표를 할 수 있습니다. 동호회 밖으로 주소를 넓게 공유하지 마세요.
  (관리자 기능은 PIN으로 막혀 있습니다)
